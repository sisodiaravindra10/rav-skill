# Kiln: one prompt, with and without the skill

**Prompt, word for word:**

> landing page for Kiln, a small ceramics studio in Jaipur that sells handmade tableware online and runs weekend wheel-throwing classes. should make people want to visit. single page.

Same model, one run each, nobody answering questions. The with-skill run had this skill only: no profile, no companion skills.

| | Without the skill | With the skill |
|---|---|---|
| Page | [without-skill.html](without-skill.html) | [with-skill.html](with-skill.html) |
| Look | Cream ground, high-contrast serif with italics, terracotta accent | Cobalt field edge to edge, wide grotesk, one ochre accent |
| Faces | Fraunces, Instrument Sans | Unbounded, Onest, Martian Mono |
| Invented prices | 3 | 0 |
| Invented phone number | yes | no |
| Invented street address | yes | no |
| Invented founding year | "Est. 2019" | none |
| Photography | none, pots drawn in SVG | none, pot rendered in the page; missing photos listed |

Both pages are competent, and the one without the skill is arguably the warmer of the two. The difference this run shows is narrower and checkable: the plain run landed on the cream, serif and terracotta look that this skill names as the default for craft subjects, and it filled the page with facts nobody supplied. The skill run avoided both.

This is one pair. Run it yourself and the pages will differ.
