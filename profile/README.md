# Your profile goes here

This folder holds your own taste and process. It is empty until you run:

```
/rav setup
```

That starts a short interview (about ten questions, one at a time) and writes two files here:

- `process.md`: how you start, how you choose, what you refuse, what you check.
- `dna.md`: your personal defaults for your own work.

Both outrank the skill's built-in rules. Both are ignored by git, so updating the skill never overwrites them and nothing here is published.

See `examples/ravindra/` for a finished profile.
